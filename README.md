Streaming Lovetide

Site de streaming desenvolvido com HTML, CSS, JavaScript e PHP. 
Apresenta seções de filmes em destaque, categorias GL e BL, e uma interface simples e responsiva.

Pastas principais:
- /css → estilos do site
- /js → scripts
- /img → imagens usadas nas páginas

Como usar:
Abra o arquivo index.php em um servidor local (XAMPP, WAMP, etc.) e acesse pelo navegador.
